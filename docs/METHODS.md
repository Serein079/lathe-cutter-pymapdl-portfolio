# 模型、方法与验证边界

## 1. 模型的工程含义

本项目分析官方车刀几何在给定面压力和对称约束下的静态结构响应，输出位移、第一主应力及 von Mises 应力。它帮助判断输入、网格和离散设置如何影响数值结果。未建立真实刀具—工件切削接触、刀屑形成、磨损、塑性或断裂模型。

基础几何是 `data/geometry/LatheCutter.anf`，SHA256 见来源记录。结构计算使用一致的 inch / psi 单位，弹性模量 1×10⁷ psi、泊松比 0.27；示例参数不能直接等同于实际刀具牌号。材料保持线弹性，`NLGEOM,ON` 开启的是几何非线性。

官方基线：SOLID285、SmartSize=4、面积 14 局部网格尺寸 0.0025 in。面积 11、16、9、10 施加 SYMM，约束对应面法向运动，不能解释成所有面上全部自由度固定。基线网格 1248 节点、4863 单元。

## 2. 压力如何加载

在面积 14 节点集合上加载压力表，局部直角坐标系用 `CSKP,11,0,2,1,13` 建立：关键点 2 是原点，1 定义 X 方向，13 定义坐标平面。表使用该局部 X 坐标，而不是简单套用全局 X。

连续函数为 `p(x)=P·sin(πx/L)`，`L=0.055 in`。官方 10 点等距表的样本最大值约 9848.08 psi，虽然名义 P=10000 psi；求解器使用表插值。21、41、81 点表包含中心点，离散峰值可到达 10000 psi。10→81 点位移改变约 1.0072%；41→81 点位移改变约 0.03864%。端点压力为零，正压力向表面内侧作用。

## 3. 单元与网格研究

SOLID285 为四节点四面体，SOLID187 为十节点二次四面体。研究分别控制局部尺寸、全局尺寸与单元类型，结果记录节点/单元数及实际输出。更换单元且同时改变网格时，应描述为联合设置比较，不能把位移差异全部归因于单元阶次。

研究图中的相邻差异定义为 `|q_fine - q_coarse| / |q_fine| × 100%`。固定点坐标为 `(-0.05771153017614537, 0.18891918500115723, -0.21029335472554514) in`，使用 VTK 对节点平均场插值，必须满足 `vtkValidPointMask=1`。该点是记录在案的内部诊断位置，不代表任意位置应力均已收敛。

81 点压力表的最后两次全局加密中，最大位移差异 0.1910%、0.1438%，固定点 VM 差异 0.4953%、0.3141%。采用 2% 位移、5% 固定点应力作为本学习项目的检查阈值；这些是自定诊断阈值，不是行业通用规范，也不是严格误差上界。

相应全局最大 VM 从约 80.16 MPa 增长到 91.85 MPa、111.27 MPa，差异 12.73%、17.45%，未达到稳定。最细模型峰值节点 206 位于面积 16 的 SYMM 边界区域。需进一步研究边界理想化、尖角/过渡几何和应力提取；当前只定位了可疑区域，未证明数学奇异性。

## 4. 力合量核对

`force_audit.py` 适用于 SOLID285 快照。识别外边界三角面，用面积 14 的加载节点集合筛选，再用节点压力平均值乘面面积向量积分。法向通过所属四面体内点校正，正压力向内。反力来源是全局坐标系、高精度 `PRRSOL,F` 总量。

线性算例外力 X 分量约 3.460870793117 lbf，反力约 −3.460870793116 lbf，相对力残差约 3.33×10⁻¹³。几何非线性算例使用变形面几何、保留初始节点压力值的积分残差约 1.91×10⁻⁷。使用初始几何比较该非线性反力会得到约 0.3107% 残差，因此应先说明积分构形与压力假设。

这里只验证力合量，未核对力矩，也未把四节点三角面公式推广到 SOLID187 二次面。这项检查不能替代边界条件正确性、实验或失效验证。

## 5. 参数与独立热结构示例

压力扫描 P=5000～15000 psi 时最大位移约 0.007935～0.023821 mm，线性拟合 R²≈0.999999948。模量 8×10⁶、1×10⁷、1.2×10⁷ psi 对应约 0.019847、0.015875、0.013228 mm，反比规律最大偏差约 0.01728%。DOE 九点拟合压力指数约 1.000676、模量指数约 −1.000705，训练点最大相对误差约 0.006758%；未设置独立测试集。

独立热示例为 SI 长方体，尺寸 0.03×0.01×0.005 m，k=45 W/(m·K)，两端 20/100 °C，其余面绝热。解析温度 `T=20+80x/0.03`，有限元温度最大误差约 7.25×10⁻¹³ °C。随后转换为结构单元，施加同节点温度，E=70 GPa、ν=0.27、α=12×10⁻⁶/K、参考温度 20 °C，固定 X=0 端。最大位移约 15.072 μm，最大 VM 约 11.028 MPa。2359 节点、1324 单元。该流程未做热应力网格收敛，也不代表车刀切削热。
